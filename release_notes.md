## Port Solano v0.1.0 — Milestone 1: playable vertical slice

Unzip and run `PortSolano.exe` (Windows x86_64). See `OWNER_TEST_CHECKLIST.md` inside the zip for what to try.

- A sunlit corner of Port Solano: four city blocks of shops and apartments, palm-lined streets, street furniture.
- Third-person player (walk / run / sprint / jump), pistol with aim, recoil and impacts.
- Six parked cars — every one can be entered, driven and exited.
- HUD with minimap, main and pause menus, graphics presets (Low–Ultra), F3 performance overlay.
- **Benchmark mode** (main menu → Benchmark): please send back the `benchmark_*.txt` it writes next to the exe.
